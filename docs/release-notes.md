X4 Launcher installs the verified MoltenVK graphics fix into a separate CrossOver copy and starts the installed Steam game.

In version 0.1.1, I fixed launching Play.command without options on macOS and added an automatic Windows Steam restart when requesting Metal HUD. All sixteen workflow tests pass.

Download X4.Launcher.zip, extract it, and open X4 Launcher. Select the Steam bottle and click Install and launch.

Required: Apple Silicon, CrossOver 26.2, Windows Steam in a 64 bit bottle and an installed copy of X4. No game or CrossOver binaries are bundled. The app is locally signed, without Apple notarization; macOS may require Open Anyway for the first launch.

Скачайте X4.Launcher.zip, распакуйте и откройте X4 Launcher. Выберите бутылку Steam и нажмите «Установить и запустить».

На моём M4 Max с 48 ГБ игра работает стабильно, без видимых артефактов. FPS я пока не измерял инструментально. Играю в разрешении 1740×1129. Свои настройки и ограничения тестов я описал в документации репозитория.
